ประเภทรายงาน

สลับประเภทได้ตลอด ข้อมูลที่กรอกไว้ไม่หาย

ช่วงเวลารายงาน

1. เหตุการณ์

2. ข้อมูลเที่ยวบิน

ต้นทาง (ชื่อเมือง / รหัสสนามบิน)
ปลายทาง (ชื่อเมือง / รหัสสนามบิน)
พิมพ์เวลาเป็น 02.30 หรือพิมพ์แค่ 0230 ก็ได้ ระบบจะจัดรูปแบบให้ตอนออกจากช่อง · รหัสสนามบินใส่ในวงเล็บเมื่อกรอกรหัสปลายทาง

3. ลูกเรือ / ผู้โดยสาร

ถ้าทราบจำนวนแล้ว เอาติ๊กออกแล้วพิมพ์ตัวเลข
สายการบินดูแลผู้โดยสารอย่างไร (ไม่บังคับ)
ถ้าเว้นว่าง บรรทัดนี้จะไม่แสดงในรายงาน ถ้าไม่ทราบจำนวนและไม่ได้กรอกข้อนี้ ข้อ 3 จะถูกตัดออกและเลื่อนเลขข้อให้อัตโนมัติ

4. OFFLOAD สัมภาระ

ถ้าไม่ได้ลากเข้าหลุมจอด ไม่ต้องติ๊ก บรรทัดนี้จะไม่แสดง
ถ้ายังไม่ทราบ เว้นว่างได้ ในรายงานจะแสดงเป็น “-”

5. เวลาออกใหม่

ถ้าทราบเวลาแล้ว เอาติ๊กออกแล้วพิมพ์เวลา เช่น 10.30 หรือ 1030 ใส่วันที่ด้วยถ้าออกคนละวัน

6. ทำการบินออกใหม่

พิมพ์เวลาเป็น 13.40 หรือ 1340 ก็ได้
